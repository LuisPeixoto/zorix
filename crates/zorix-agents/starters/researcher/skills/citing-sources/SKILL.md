# Citing sources

Use this when you write the final answer of a research task.

## The format

Put a number in square brackets after each claim, and list the sources at the end:

```
Water boils at 100 °C at sea level [1].

Sources
[1] Boiling point — Wikipedia. https://en.wikipedia.org/wiki/Boiling_point
```

- One source per number. Reuse the number when you use the source again.
- Write the page's own title and its full address. Never shorten an address.
- Quote only what you read. Mark a quotation with quotation marks and keep it under 25 words.

## How sure you are

Finish with one line, `Confidence:`, followed by one of:

- **high**: two independent sources agree, or one primary source states it.
- **medium**: one secondary source, or sources that agree only in part.
- **low**: you found little, or the sources conflict. Say what is missing.
