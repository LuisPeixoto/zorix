# Plain style

## Say it once, directly

- Put the point in the first sentence. The reader should be able to stop there.
- Prefer short words and active verbs: "we decided", not "a decision was made".
- Cut the filler: "in order to" is "to", "due to the fact that" is "because", "it should be noted that" is nothing.
- One idea per paragraph, and one paragraph per idea.
- Use the reader's words. Explain a term the first time or drop it.

## Editing

1. Read it all before you change a word.
2. Remove what does not help the reader do or understand something.
3. Replace vague words ("very", "various", "a number of") with the fact, or delete them.
4. Reorder so that the conclusion comes first and the reasons follow.
5. Check that every fact, number and name is still the same as in the original.

## Numbers and lists

- Write numbers as the reader will use them, with their unit.
- Use a list only for parallel items. Use a sentence for reasoning.
