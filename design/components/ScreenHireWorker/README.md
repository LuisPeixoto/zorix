# Hire a worker

The modal that makes an agent a worker.

- Built from Modal, Field, Select, Input and AutonomyDial.
- Fields: the agent (one that is not a worker yet), role, department, who it reports to, autonomy and its budget and time limits.
- A worker cannot be freer than who it reports to, and its budget cannot be larger. The modal says the limit beside each field. Every chain ends at you.
- Hiring does not change the agent: its tools, access and versions stay as they are.
