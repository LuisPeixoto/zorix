# New project

The modal that makes a project.

- Built from Modal, Field, Input, Textarea and Select.
- Fields: name, key (2 to 5 capitals, mono; unique), description, start and due dates, a manager (an agent, optional) and a cost limit for each task run.
- The key starts the numbers of its tasks: `OPS-1`, `OPS-2`. A key cannot be reused.
- A manager plans the project and asks before it changes anything; the limit narrows every run a task starts.
