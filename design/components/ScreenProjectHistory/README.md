# Project history

Everything that happened to the project's tasks, newest first, in plain sentences.

- Built from PageHeader, Tabs, Chip filters, List, Avatar and Badge.
- Days are labels; each line says who did what to which task (the key in mono), when, and where it came from ("from its run"). Moves, runs, assignments, deliverables, comments and approvals appear.
- A move to Done that a manager asked for shows *Approved by you* (or *Refused by you*). A task that went to Review shows *Needs you* until a person has acted.
- Filters: All, Moves, Runs and Approvals.
