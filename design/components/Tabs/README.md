# Tabs

Segmented control and tabs: switch between views of the same thing.

- **Segmented** (`options`, `bind:value`) for two to five short choices that change a setting in place: Light · Dark · System, Day · Week · Month. Arrow keys move.
- **Tabs** (`tabs`, `bind:value`) for sections of one object: Overview, Events, Tools. A count sits after the label in a `zx-count` pill.
- The active segment is a raised `panel` tile; the active tab has a 2px `accent` underline.
