# Command Center

The home of an operator: live figures, spend against budget, everything waiting for a person, the health of every connection and the live log.

- Built from PageHeader, MetricTile, ChartPanel, List, HealthGrid and LogStream.
- The one primary action is Export report. Approvals open the Inbox, where each opens an ApprovalCard.
- Figures refresh live; only the live dots and the log move.
