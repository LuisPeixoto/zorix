# TaskCard

One task: key, priority, title, progress, due date, dependencies and who has it.

- Priority is a flag, a word and a tone: Urgent `priority-urgent`, High `priority-high`, Normal `priority-normal`, Low `priority-low`.
- A late due date turns `err` and says "Today" or "2 days late".
- Deliverables and dependencies show as counts with an icon; the Drawer lists them.
