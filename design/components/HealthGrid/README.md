# HealthGrid

The health of every provider, integration and server at a glance: a state and 24 hours of history.

- Each cell: mark, name, StatusPill, a 24-bar uptime strip (one bar an hour) and one line of the figure that matters.
- Bars are `ok`, `warn` or `err`; the strip has a text label for screen readers.
- Sort failing first. A failing cell opens its logs.
