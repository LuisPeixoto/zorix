How ZORIX is used from other tools.

Use ZORIX from other tools

Claude Code, Cursor and other MCP clients can search ZORIX's memory and, if you say so, start runs. Add this to the client:

zorix mcp serve --allow-runs --allow math.evaluate
Start runs
Adds --allow-runs. Runs use only the tools and files named in the command.
Answer approvals from the client
Adds --allow-approvals. Every answer is confirmed by you in the client; a client that cannot ask is refused.
Read every run
Adds --allow-read-runs. Off: a client follows only the runs it started.
