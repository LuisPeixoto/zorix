# BrandMark

The ZORIX mark: the `layers` icon on a tile filled with the brand gradient, beside the word ZORIX set in `lead`.

- Use the small tile (28px, `radius-lg`) with the wordmark in the toolbar, and the large tile (56px, `radius-2xl`) on empty states and the About screen.
- The gradient runs 135° from `accent` through a blue-violet to `accent-2`. It is the only gradient fill in the product besides the primary button and Marketplace art.
- The tile carries white, never `accent-fg`: the gradient is dark enough in both themes.
- The app icon (assets/Logos) is the same tile with a white Z; use it only where the operating system shows the app.
- Do not recolour the tile, outline it, or set the word in another face or weight.
