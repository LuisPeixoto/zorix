# WorkerCard

A virtual employee: face, name, role, status and three figures that matter for the role.

- The status dot on the avatar: `ok` working, `warn` waiting for a person, `err` stopped, none when idle.
- Figures are tabular and labelled: tasks, on-time rate, eval score, spend this week.
- A person's card is dashed with a round avatar, so humans and agents are never confused.
