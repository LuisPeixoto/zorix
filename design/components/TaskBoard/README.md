# TaskBoard

A project's tasks in columns by state, assigned to people or agents.

- Lanes are `panel-2` wells; cards are `panel`. A lane header has a state dot, the name and a count.
- Dragging a card tilts it 1.5° and lifts it to `sh-3`. Dropping on Review notifies the reviewer.
- People are round avatars with initials; agents are square avatars. A task assigned to an agent starts a run when it moves to In progress.
- The same tasks appear as a list and a timeline; the board is the default view.
