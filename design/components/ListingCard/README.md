# ListingCard

An agent, team, skill, integration or workflow offered in the Marketplace.

- Art band in the brand gradient (agents, teams), cyan (workflows) or ink (skills, integrations), with a 12px dot texture. The icon tile overlaps it.
- Verified publishers carry `badge-check` in `accent`. Kind, rating with its number, and install count are always shown.
- Install opens a sheet that lists every permission the item asks for; nothing is granted by installing alone.
