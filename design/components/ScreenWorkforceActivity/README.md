# Workforce activity

What the workers did, as it happens, newest first.

- Built from PageHeader, Stat, Segmented, LogStream, Chip and Avatar, with the same right panel.
- Each line has the time, a level word (OK, INFO, WAIT, WARN, ERR), the worker and one sentence. Calls that ran without asking because of the worker's level, proposals from a worker at Suggest, approvals that wait for you, budget warnings, level changes and the weekly plan and report all appear.
- A paused stream says how many lines arrived since. A line opens its run in a Drawer.
- Secrets are redacted before a line is stored.
