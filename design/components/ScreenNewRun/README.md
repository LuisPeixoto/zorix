# New run

The form that starts a run: who runs it, what it should do, what it may use, its limits, and a summary of what it can do before you start.

- Built from Segmented, selectable Cards, Field, Textarea, Chip, Input, Switch, Callout and KeyValue.
- Grants can only narrow what an agent or team already has; chips marked "asks" will wait for a person.
- Start run is the only primary; ⌘↵ starts it from anywhere in the form.
