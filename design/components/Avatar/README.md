# Avatar

The face of an agent, a virtual employee or a person.

- Agents: an emoji or an icon on a tint of their colour (`accent`, `accent-2`, `ok`, `warn`, `info`), `radius-xl`-ish square.
- People: initials on a round avatar, so a human is never mistaken for an agent.
- Optional status dot at the corner; stacks overlap by 6px with a `panel` ring.
