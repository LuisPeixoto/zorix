# Primitives

The small parts: Spinner, Dot, Kbd, Skeleton and Divider.

- **Spinner** inside a loading button or beside "Starting…". **Dot** before a state word. A live dot pulses only while something happens now.
- **Kbd** for shortcuts: ⌘K opens the command palette, ⌘⇧D the design system, ⌘↵ sends.
- **Skeleton** in the shape of what is loading, never a spinner for a whole page.
