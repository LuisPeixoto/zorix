# Workflow editor

The visual editor of a workflow: a palette of step kinds, the canvas, and the inspector of the selected step. The same canvas is the live view of a run.

- Built from TriggerChip, WorkflowCanvas, WorkflowNode, the palette list, Field, Chip, ToggleRow and run bars.
- Edits make a draft of the next version; Publish v5 is the primary action and the next trigger uses it.
