# CommandPalette

⌘K / Ctrl K: go anywhere, start anything, by typing.

- Props: `bind:open`, `commands` (`id`, `label`, `group`, `icon`, `hint`, `keywords`, `run`). Fuzzy search; arrows and Enter; a combobox for screen readers.
- Glass surface. Matched letters in `accent`. Groups: Go to, Start, Workflows, Agents, Settings.
