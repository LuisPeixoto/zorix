# Server sandbox

How a local MCP server is confined: the mode, the network, the folders, and what this computer can really enforce.

- Built from Segmented, ToggleRow, KeyValue, Badge, Callout and Button, in the server drawer's Connection tab.
- What is enforced is stated per system, never assumed: Windows says plainly that native mode does not confine files or the network.
- A server added before sandboxing keeps running as before and says so, with a warning, until a person turns it on.
