# AutonomyDial

How much a virtual employee or manager may do without asking: five levels, set per role.

- Levels: Suggest (proposes, a person acts) · Ask (acts after each approval) · Notify (acts, then reports) · Budgeted (acts within limits) · Full (acts, reports weekly).
- The dial never overrides policy: a tool that always asks still asks.
- The current level is a raised tile; the bars fill up to it in `accent`.
