# Workforce list

The same workers as the org chart, as a table that can be sorted by column.

- Built from PageHeader, Stat, Segmented, Table, Badge and Avatar, with the same right panel as the org chart.
- Columns: worker (avatar and name, indented under who it reports to), role, department, reports to, autonomy (Badge), tasks, on time, eval and spend this week.
- A manager's tasks, on-time rate and spend include everyone who reports to it. A dash means there is nothing to measure yet, as for an eval that has never run.
- A row selects the worker and opens its panel. Opening the row again, or its name, goes to the worker's page.
