# ChatBubble

One message in a conversation with an agent or a team.

- Yours: right, a solid accent bubble with `accent-fg` text. The agent's: left, a `panel` bubble with its avatar, name and version.
- While a model writes, the text grows with a blinking caret; when the step is stored it replaces the draft.
- Tool calls, approvals and delegations sit between bubbles as cards, in the order they happened.
