# Project deliverables

What the project has produced, grouped by task.

- Built from PageHeader, Tabs, List, Badge and Avatar.
- Each group has the task key, its title, its state and who has it. Each row is one deliverable with an icon for its kind (answer, link, pull request, file), its title, who made it and when, and *Open*.
- A run's final answer is a deliverable. So is whatever an agent added with `tasks.add_deliverable` and whatever a person attached.
- The tab's count is the number of deliverables in the project.
