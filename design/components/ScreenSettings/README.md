# Settings · permissions and policy

The rules that decide what anything in ZORIX may do, how approvals behave, and who can approve.

- Built from the settings nav (the sidebar nav pattern), PageHeader, a rules table with effect Badges (Allow `ok`, Ask first `warn`, Deny `err`), ToggleRow and List.
- New rule is the primary action. Deny rules cannot be overridden by an agent, a workflow or an install.
