# Card

The surface for one subject: a header with an icon and actions, a body, an optional footer.

- Props: `title`, `icon`, `padding`, `interactive`; snippets `actions`, `footer`.
- `panel` on `bg`, framed by `line`, `radius-2xl`, `sh-card`. The header sits on `panel-2`.
- Interactive cards lift 1px and take `sh-2` on hover. Don't nest cards; use a List or a well inside.
