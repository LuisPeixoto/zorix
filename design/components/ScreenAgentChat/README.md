# Agent chat

A conversation with an agent or a team: messages, delegations, tool calls and approvals in the order they happened, with what the team knows and spent beside it.

- Built from List, ChatBubble, DelegationCard, Callout (inline approval), Composer, Avatar and KeyValue.
- Three columns: conversations, the thread, and the team panel. The composer's send button is the only solid accent besides an open approval.
