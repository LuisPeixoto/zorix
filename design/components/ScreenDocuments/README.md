# Documents

The folders ZORIX can search and cite, kept up to date as they change.

- Built from Card, Badge, Callout, ToggleRow and Button.
- Each folder says **Watching** (a live dot) when it is checked for changes as they happen, or **Not watching** with the reason in its last line when it cannot be (a drive the system will not watch is checked every ten minutes instead). A change is read again within seconds; a file whose content did not change costs one read.
- A folder that holds scanned PDFs shows how many were read by OCR (*6 via OCR*) and how many were not (*2 scans not read*), with a warning that links to the switch below.
- **Reading scans** is one switch, off by default. Turning it on downloads two small models once and says when they are ready; nothing leaves the computer.
