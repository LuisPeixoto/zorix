# Server requests

What an MCP server may ask while its tool runs: a model answer (sampling) or something from the person (elicitation).

- Built from ApprovalCard (head, args, foot), KeyValue, Field and Badge, in the run view and the Inbox.
- The card shows the exact request; the answer is bound to it and can be given once. Unanswered requests are declined after five minutes.
- A page is only opened on a click, with its domain shown first.
