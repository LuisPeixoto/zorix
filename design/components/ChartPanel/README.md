# ChartPanel

A chart in a Card: a headline figure, a range control, the chart and a breakdown.

- Series colours in order: `series-1` (the subject), `series-2` (the comparison, dashed), `series-3`, `series-4`, `series-5`. More than five: group the rest as Other in `faint`.
- One scale for marks and labels; gridlines in `line-soft`; axis text in `faint`; the latest point emphasised with a ring.
- Every chart has a text alternative that states the headline figure.
